# Constraints

## Hard constraints

Requirements that cannot be traded away by a Skill or Direction.

## Product constraints

Content, behavior, information, data, legal, compliance, accessibility, and localization constraints.

## Technical constraints

Stack, browsers, performance, deployment, component library, and integration constraints.

## Locked decisions

Pointers to accepted Decisions that require explicit reopening.

## Assumptions

Each assumption includes confidence, source, and validation path.

## Out of scope

Work ruled beyond the current destination.
