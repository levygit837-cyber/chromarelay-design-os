# Direction A — Instrument

**Lens:** the page is a measuring instrument, not an advertisement.

- **Composition:** single centered column, 640px max. The headline is the latency number
  `41ms` at 128px. Everything else is subordinate and small.
- **Typography:** one family, `JetBrains Mono`, three sizes only (128 / 15 / 13). No
  sans-serif anywhere. Tabular figures throughout.
- **Color:** paper `#F4F2ED`, ink `#14161A`, one signal green `#0B7A4B`. Three values total.
- **Surfaces:** no cards, no borders. Separation by whitespace and baseline alignment only.
- **Motion:** the latency digit counts once from 0 on load, 400ms, then never moves again.
- **Signature:** the number is the logo.
- **System potential:** the "one large tabular number + small monospace label" pattern
  extends to any metric surface.

**Divergence axes vs peers:** light ground, single column, number-as-hero.
