# Product Brief — watchtest landing page

## Product truth
`watchtest` is a command-line tool that watches source files and reruns the affected
tests on save. Single binary, no config file required, works with existing test runners.

## Primary user
A developer who already has a test suite and runs it manually. They are not looking for
a new test framework; they want the feedback loop to close without them typing.

## Primary task on this surface
Decide in under 30 seconds whether this tool fits their stack, then copy the install
command. Secondary: understand what makes it different from `nodemon --exec` or
`jest --watch`.

## Desired perception
Fast, precise, unfussy. Built by someone who uses it daily. Not a startup landing page.

## Constraint draft
- Single self-contained HTML file, no build step
- 375px to 1440px
- The install command must be selectable and copyable
- Terminal output shown on the page must be plausible real output, not decorative

## Open creative space
Composition, typography, color, motion, and how (or whether) to represent the terminal.

## Material ambiguity accepted
No real brand assets exist and no pricing model is defined. Both are accepted as open;
this Run treats the tool as pre-brand and free.
