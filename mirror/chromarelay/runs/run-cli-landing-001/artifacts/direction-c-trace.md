# Direction C — Trace

**Lens:** the page is a continuous signal that spikes when you save.

- **Composition:** full-bleed horizontal bands stacked vertically, each band one beat of the
  save→verdict cycle. No max-width; content is inset 8vw. Reading is horizontal within a
  band, vertical between beats.
- **Typography:** `Space Grotesk` for headings at tight tracking (-0.03em), `Roboto Mono`
  for output. Headings are lowercase throughout.
- **Color:** near-black ground `#0A0A0B`, cool white `#F2F4F7`, and a two-stop signal ramp
  from dim `#3A4A45` to live `#3DDC97` used to encode state across bands.
- **Surfaces:** bands separated by a 1px rule at 12% opacity; no cards.
- **Motion:** a 2px trace line runs along the top of each band, dim until the band enters
  the viewport, then brightens left-to-right over 600ms. Four instances on the page.
- **Signature:** the trace line itself, and the ramp encoding state.
- **System potential:** the band-per-beat structure extends to any sequential process surface.

**Divergence axes vs peers:** full-bleed horizontal bands, cool dark ground, state-encoding color ramp.
