watchtest — test feedback loop

41ms milliseconds

median time from saving a file to seeing the verdict, across 12k runs

brew install watchtest

It watches what you actually import. watchtest builds the dependency graph once at startup and updates it on change, so saving a leaf module runs the three tests that touch it, not the whole suite.

It uses the runner you already have. There is no new assertion library and no config file. Point it at your existing test command and it takes over the scheduling.

It does not try to be your test framework. No coverage reports, no snapshot management, no dashboard. It closes the loop between saving and knowing, and stops there.
